# AI Interview Platform

An AI-powered mock interview platform that conducts resume-based HR interviews using LLMs and generates personalized interview feedback.

## Features

- JWT Authentication
- Resume Upload
- Resume Parsing
- AI HR Interview
- Interview History
- AI Feedback Report
- Resume-based Question Generation

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Framer Motion

Backend:
- Node.js
- Express
- MongoDB

AI:
- FastAPI
- LangGraph
- LangChain
- Groq. .
